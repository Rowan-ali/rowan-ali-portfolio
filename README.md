## 🚀 Run the Portfolio Locally

### Option 1 — Quick preview
Download or clone the repository, then open `index.html` in your browser.

### Option 2 — Recommended local server
Clone the repository:

```bash
git clone https://github.com/Rowan-ali/rowan-ali-portfolio.git
cd rowan-ali-portfolio
```

Start a local server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

You can also use the **Live Server** extension in VS Code and open `index.html` with **Open with Live Server**.
